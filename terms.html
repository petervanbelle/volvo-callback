Application: Home Dashboard (private Node-RED dashboard) · Last updated: 13 November 2026

1. Purpose

This application is a private, non-commercial home dashboard. It reads data of the owner's own Volvo vehicle through the Volvo Cars APIs and displays it on a dashboard running on the owner's home network.

2. Users

The application is used exclusively by its owner for his own vehicle. It is not offered, sold or made available to any third party, and no other user accounts are supported.

3. Data

Vehicle data is retrieved only with the explicit consent of the owner given through Volvo ID. Data is processed and stored only on the owner's own device in his home. It is not shared, sold or transferred to third parties. See the Privacy Policy.

4. Read-only use

The application only requests read access to vehicle data. It does not send commands to the vehicle.

5. No warranty

The application is provided "as is", without any warranty. Data shown may be delayed or incomplete and must not be relied upon for safety-related decisions.
